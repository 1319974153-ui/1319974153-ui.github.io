    观引 GEO 工作台

    观引是面向 GEO 实践的工作台，用于组织问题、整理 AI 回答与引用来源、管理内容及发布记录，帮助使用者追踪公开信息如何被发现、描述和引用。项目强调保存可核对的证据，区分内容发布、搜索收录与 AI 实际引用。源码免费开放，采用 MIT 许可；外部模型和云服务费用另计。

    分工：温舒提出产品目标与工作流；Codex协助实现、测试和开源材料整理。

    要解决的问题
    企业、品牌和个人发布介绍后，很难区分 AI 是否正确识别了主体、引用了官网，还是仅回答了带姓名的提示。观引把问题、原回答、来源和发布回执组织在同一工作流，便于回查每个判断的依据。
    核心流程
    建立资料与问题 → 导入原回答和引用 → 人工核对判断 → 整理内容与发布记录 → 按同一问题复核变化。不同模型、入口、模式和时间分别记录。
    工程取舍
    API 返回不等于消费者搜索；试用演练不进入正式指标；未标注的引用与推荐保留未知。重复导入要识别已存在的记录，历史回答继续对应提问时的问题版本。
    本次可复核的结果
    2026年10月14日，在本地开发提交 bf256ea0b59f1e2a095352aa4750b46f00c644eb 上执行回答导入和目标证据两组定向测试，14项通过。测试使用构造数据，验证记录与判断逻辑；没有调用外部AI，也不是客户上线效果。
    适合什么需求
    需要整理品牌、产品或个人的公开资料，记录多平台AI回答，追踪内容与引用证据的团队。公开源码支持自行评估；如需业务流程适配，可沟通需求。
    使用边界
    自有源码免费、MIT许可，第三方模型及云服务费用另计。本地版是单用户实例；消费者搜索目前需要辅助采集与核对，不承诺全平台无人值守或必然推荐。

    技术：JavaScript · Node.js · SQLite · Cloudflare Worker
